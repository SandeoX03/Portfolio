# Sushant Tandukar — Portfolio

A modern single-page portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Sections

- **Home** — Hero with introduction and call-to-action
- **About** — Personal story, highlights, and honors
- **Skills** — Cybersecurity, cloud, development, and soft skills
- **Projects** — Featured work and hands-on labs
- **Experience** — Professional and leadership roles
- **Education** — Academic background
- **Certificates** — Industry certifications
- **Contact** — Email form and social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data/portfolio.ts` to update your content, links, projects, and contact details.
